# Reflection

## 1. Introduction

This assignment helped me understand more about PL/SQL and how it can be used to solve database problems. I worked with GOTO statements, functions, exception handling, and functions used in SQL. I also worked on a payroll validator that combined some of these concepts.

## 2. What I Learned About GOTO Statements

I learned that the GOTO statement can be used to move the program from one part of the code to another part. It can be useful in some situations, but using too many GOTO statements can make the code difficult to understand.

I also learned that some GOTO statements are not allowed in PL/SQL. In the illegal GOTO task, I saw the error and learned how to correct the code.

The task where I rewrote the program without GOTO helped me understand that the same result can often be achieved using normal PL/SQL structures. This can make the program easier to read and maintain.

## 3. What I Learned About Functions

I learned how to create and use PL/SQL functions. A function performs a specific task and returns a value.

In this assignment, I worked with functions for annual salary, years of service, tax calculation, and department name. I learned how to pass values to a function and use the returned result.

I also learned how functions can be used inside SQL statements. This helped me understand how PL/SQL functions can work together with SQL queries.

## 4. Exception Handling

I learned that errors can happen when a PL/SQL program is running. Exception handling allows the program to handle these errors instead of stopping unexpectedly.

This assignment helped me understand why it is important to think about possible errors when writing PL/SQL programs.

## 5. Payroll Validator

The payroll validator helped me combine the concepts I learned in the assignment.

I learned how to create a function that checks payroll information and returns a result based on the data. This task helped me understand how functions can be used to perform validation in a database system.
